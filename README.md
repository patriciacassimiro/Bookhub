📚 BookHub — Plataforma Web de Livros

Plataforma web desenvolvida para pesquisa e consulta, utilizando a Google Books API. O projeto inclui sistema de utilizadores, avaliações, pontuação e descontos, combinando Front-end, Back-end e base de dados.

O BookHub é uma plataforma web desenvolvida como projeto final do curso de Desenvolvimento Web e Programação.

A aplicação permite aos utilizadores pesquisar livros através da Google Books API, consultar informações detalhadas sobre cada obra e interagir com a plataforma através de avaliações.

1. Funcionalidades

Pesquisa de livros através da Google Books API
Sistema de login e gestão de sessões
Registo e autenticação de utilizadores
Sistema de avaliações
Sistema de pontuação
Sistema de descontos
Armazenamento e gestão de dados através de MySQL
Interface responsiva
Integração com API externa
